# モダン PDF ビューアー (Modern PDF Viewer)

React 19 + TypeScript + Vite + Tailwind CSS + PDF.js で構築された、高機能かつ軽量なWebベースのPDF閲覧アプリケーションです。

🌐 **オンラインで試す**: [https://orga29.github.io/web-pdf-viewer/](https://orga29.github.io/web-pdf-viewer/)

## 主な機能

- 📄 **多様なPDF読み込み**
  - ファイルのドラッグ＆ドロップ（初期画面および閲覧中いつでも可能）
  - 「開く」ボタンからのローカルファイル選択
  - ワンクリックで動作確認できるサンプルPDF機能
- 📑 **サムネイル＆目次サイドバー**
  - 各ページのミニプレビュー一覧（クリックでジャンプ、現在ページをハイライト表示）
  - PDFのアウトライン（しおり・ブックマーク）階層ツリー表示とジャンプ
  - サイドバーの開閉トグル
- 🔍 **表示＆ナビゲーション制御**
  - ページ送り（前へ/次へ、ページ番号直接入力、マウスホイール順送り/逆送り）
  - ズーム（拡大/縮小、50%〜200%、幅に合わせる、全体を表示）
  - 単一ページ表示 ⇄ 連続スクロール表示のワンクリック切替
  - ページの90度時計回り回転
  - 全画面（フルスクリーン）表示モード
  - PDFファイルのダウンロードおよび印刷機能
- 🖱️ **マウス操作**
  - **ホイール下スクロール**: 次のページ（順送り）
  - **ホイール上スクロール**: 前のページ（逆送り）
    *(拡大表示時はページ内をスクロールし、端に達すると次の/前のページへシームレスに遷移)*
  - **Ctrl + ホイール**: ズームイン / ズームアウト
- ⌨️ **キーボードショートカット**
  - `←` / `PageUp`: 前のページ
  - `→` / `PageDown` / `Space`: 次のページ
  - `Home` / `End`: 最初 / 最後のページ
  - `Ctrl` + `+` / `-`: ズームイン / ズームアウト
  - `Ctrl` + `1`: 原寸表示 (100%)
  - `P` / `Alt` + `P` / `Ctrl` + `0`: 全体を表示
  - `W` / `Alt` + `W`: 幅に合わせる
  - `H` / `Alt` + `H`: 高さに合わせる *(隠しショートカット)*
  - `R`: 90度時計回りに回転
  - `F`: 全画面表示の切り替え

## 起動方法

### 開発サーバーの起動
```bash
npm run dev
```
ブラウザで [http://localhost:5173](http://localhost:5173) を開きます。

### プロダクションビルド（Web版）
```bash
npm run build
npm run preview
```

### 単一ポータブルHTML版の生成（完全ローカル・オフライン用）
```bash
npm run build:singlefile
```
実行すると、プロジェクト直下に **`pdf-viewer.html`** が生成されます。
このHTMLファイル1つをダブルクリックするだけで、インターネットやサーバーのない完全ローカル環境でもPDFビューアーが利用可能です。
他の人に配布する際も、この `pdf-viewer.html` をメールやUSB等で渡すだけで安全に使ってもらえます。
